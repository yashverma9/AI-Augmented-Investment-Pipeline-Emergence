# DocsAlot CLI
Let Claude or Codex create and maintain good looking docs

**Call: Pass**


## What they do
Claude Code, Codex or Backboard are great at writing a first draft. DocsAlot turns that draft into a genuinely good-looking docs site, and gives your agent a complete workflow for keeping it current. Ask in plain English to create or pull docs, preview changes, migrate existing content, save versions, and publish only when approved. No commands to memorize or documentation workflow to manage by hand. You describe the outcome; your agent handles the work while you stay in control
